納税者本人に生計を同じくする扶養親族がいる場合一定額が控除される


| 扶養親族年齢                 | 控除額                 |
| ---------------------- | ------------------- |
| 16歳以上19歳未満             | ==38万円==            |
| 19歳以上23歳未満([[特定扶養親族]]) | ==63万円==~3万円        |
| 23歳以上70歳未満             | 38万円                |
| 70歳以上                  | 同居 58万円<br>非同居 48万円 |
[^1]
[^1]: 年齢は12/31時点において換算する

> [!NOTE]
> 配偶者は扶養者にはならない



> [!NOTE]
> 以下の場合には扶養者控除を受けられない
> - 扶養者が[[青色事業専従者給与]]の対象となっている場合
> - 扶養者の[[合計所得金額]]が==58万円==超
