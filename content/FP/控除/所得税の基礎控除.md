合計所得金額に応じて控除額が設定される

| 合計所得金額   | 基礎控除額    |
| -------- | -------- |
| 200万円以下  | ==95万円== |
| ⋮        | ⋮        |
| 2350万円以下 | ==58万円== |
| ⋮        | ⋮        |
| 2500万円超  | -        |


> [!NOTE]
> 以下の場合には基礎控除を受けられない
> - 納税者本人の合計所得金額が==2500万円==を超えている場合
> 

> [!NOTE] 103万円の壁
> 
> [給与所得控除](給与所得控除額.md)の下限(55万円) + 基礎控除の上限額(48万円) = 103万円
> [給与所得控除](給与所得控除額.md)の下限(65万円) + 基礎控除の上限額(95万円) = 160万円
