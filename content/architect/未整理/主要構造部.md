防火上の重要な部分

- 壁
- 柱
- 床
- 梁
- 屋根
- 階段


```sheet

{
    classes: {
        c1: {
            "color": "cyan",
        },
        c2: {
            backgroundColor: "#555",
        }
    },
}

--- 

| 部位        | ----: ~ .c2   | 除外される部分     |
| ------------| ------ | -------- | 
| 壁     | ----   | 構造上重要でない間仕切壁  | 
| 柱     | ------ | 構造上重要でない間柱、付け柱 | 
| 床     | ------ | [[揚げ床]]、最下階の床\[^1] | 
| 梁     | ------ | 小梁 | 
| 屋根     | ------ | 庇 | 
| 階段     | ------ | 局部的な小階段、屋外階段 | 
```

[^1]: 最下階の基礎も対象外
